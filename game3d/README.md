# Forest Bloom 3D

Полноценная 3D-игра от первого лица: лес, меч, волны теней, собираемые грибы здоровья, меню, настройки, пауза. Игровая логика написана на Rust (WebAssembly), рендер — Three.js, все библиотеки и ассеты лежат локально, без CDN и внешних crates.

## Быстрый запуск

Самый простой способ: скачать из GitHub Release файл **`ForestBloom3D.html`** и открыть его двойным щелчком в современном браузере. Это один самодостаточный файл (~140 МБ): внутри — Rust/WASM, Three.js, модели, текстуры и звуки.

Для разработки:

```bash
cd game3d
./build.sh          # cargo build --target wasm32-unknown-unknown + make_single.py
python3 serve.py    # http://localhost:8081
```

`serve.py` отдаёт правильный MIME для `.wasm` и `.gltf`.

## Управление

| Действие | Клавиша |
|---|---|
| Движение | WASD / стрелки |
| Взгляд | мышь |
| Удар мечом | ЛКМ / пробел |
| Бег | Shift |
| Прыжок | Пробел (в момент нажатия) |
| Пауза | Esc |
| Меню | кнопки на экране |

В настройках: чувствительность, FOV, громкость, качество (низкое/среднее/высокое), тени, туман, инверсия оси Y.

## Что внутри

- `src/lib.rs` — Rust: игрок, физика, выносливость, урон, AI врагов, волны, подборы, очки, event queue.
- `main.js` — Three.js: сцена, небо с солнцем, туман, направленный свет с тенями, инстансинг травы, загрузка glTF, анимации, HUD и меню.
- `models/` — 45 glTF/GLB моделей из архива: деревья, кусты, грибы, камни, цветы, руины, мечи, персонажи и библиотека анимаций `UAL2_Standard.glb`.
- `textures/`, `sounds/` — текстуры и звуки из архива.
- `vendor/` — локальные копии Three.js r146, GLTFLoader и PointerLockControls.
- `make_single.py` — сборка одного HTML со всеми ресурсами в data URI.

## Производительность

- Инстансинг травы (700/1600/3200 в зависимости от качества).
- Статические модели деревьев и камней получают `matrixAutoUpdate = false`.
- Тени PCFSoft, карта 2048², отключаются в настройках.
- Тон-маппинг ACESFilmic, sRGB, экспозиция 1.15.
- Уровень качества управляет pixelRatio и количеством объектов.
